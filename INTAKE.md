
Folder names can be anything recognizable — I'll rename and move them into `public/images/projects/<slug>/`. `assets-inbox/` is gitignored, so nothing lands in the repo twice.

**What works well:**
- ~2400px wide, PNG or JPG. Next.js downscales per breakpoint, so oversized beats undersized.
- One good hero shot per project is enough. Add more only where a second screen genuinely shows something different.
- Real data beats lorem ipsum. Crop out browser chrome and your bookmarks bar.
- Mobile apps: portrait screenshots — I'll give those projects the `tall` grid slot.
